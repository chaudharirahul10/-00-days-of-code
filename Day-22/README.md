# Day 22 - Union of Two Arrays

## 📌 Problem

Given two arrays, find the union of both arrays.

The union should contain all unique elements from both arrays without repeating any element.

## 💡 Example

### Array 1

1 2 2 3 4

### Array 2

2 4 5 6

### Output

Union of two arrays is: 1 2 3 4 5 6

## 🧠 Approach

1. Traverse the first array.
2. Check whether the current element has already appeared before.
3. If it is not a duplicate, print the element.
4. Traverse the second array.
5. Check whether the element already exists in the first array.
6. Also check for duplicates inside the second array.
7. Print only unique elements.

## ⏱️ Complexity

- **Time Complexity:** O(n × m)
- **Space Complexity:** O(1)
