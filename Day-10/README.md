# Day 10 – Frequency of an Element

## 📌 Problem

Find the frequency (number of occurrences) of a given element in an array.

## 🧠 Concepts Used

* Arrays
* `for` loop
* `if` condition
* Counting occurrences using a counter variable
* `sizeof()` to calculate the array size
* Array traversal

## 🔍 Approach

1. Store elements in an array.
2. Select a target element.
3. Traverse the complete array using a `for` loop.
4. Compare each element with the target using an `if` condition.
5. Increment the counter whenever a match is found.
6. Print the total frequency of the target element.

## 💡 Example

For the array:

`{10, 20, 10, 30, 10, 40, 20, 50}`

Target: `10`

Frequency: **3**

## 🎯 Learning Outcome

Learned how to traverse an array and count how many times a specific element appears in it using basic C++ concepts.

## 🛠️ Language

* C++
