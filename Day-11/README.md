# Day 11 - Move All Zeros to the End

## 📌 Problem
Given an array containing zero and non-zero elements, move all the zeros to the end of the array while maintaining the order of the non-zero elements.

## 💡 Example

### Input
0 1 2 0 3 0 4 0 5

### Output
1 2 3 4 5 0 0 0 0

## 🧠 Concepts Used
- Arrays
- For Loop
- While Loop
- Conditional Statements
- Two-index approach
- In-place array modification

## ⏱️ Complexity
- Time Complexity: O(n)
- Space Complexity: O(1)

## 🎯 What I Learned
- How to move elements inside an array
- How to maintain the order of non-zero elements
- How to solve the problem without using an extra array
