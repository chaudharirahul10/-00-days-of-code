# Day 15 - Right Rotate Array by One Position

## 📌 Problem

Given an array, rotate all elements to the right by one position.

## 💡 Example

### Input

1 2 3 4 5

### Output

5 1 2 3 4

## 🧠 Approach

1. Store the last element in a temporary variable.
2. Shift all remaining elements one position to the right.
3. Place the stored last element at the first position.
4. Print the rotated array.

## 🛠️ Concepts Used

* Arrays
* For Loop
* Array Traversal
* Element Shifting
* Temporary Variable

## ⏱️ Complexity

* Time Complexity: **O(n)**
* Space Complexity: **O(1)**

## 🎯 What I Learned

* How to right rotate an array.
* How to shift elements from right to left.
* How to preserve an element using a temporary variable.
* How to perform an in-place array operation.
