# 📌 Day 08 – Second Largest Number

## 🧠 Concepts Used

* **Arrays** – Array ke elements ko store aur traverse karne ke liye.
* **`<climits>` Header** – `INT_MIN` ka use karke `largest` aur `second_largest` ko minimum possible integer value se initialize kiya.
* **Array Traversal** – `for` loop se poore array ke har element ko check kiya.
* **Conditional Statements** – `if` aur `else if` ka use karke largest aur second largest element identify kiya.
* **Variable Updating** – Jab naya largest element mila, previous largest ko `second_largest` mein shift kiya.
* **Duplicate Handling** – `arr[i] != largest` condition se same value ko second largest banne se roka.
* **Edge Case Handling** – Agar second largest element exist nahi karta, to `INT_MIN` check karke appropriate message display kiya.
* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(1)`

## 🎯 Key Learning

Is problem se **array traversal, comparison logic, variable updating, `INT_MIN`, duplicate handling aur edge cases** ko practically understand kiya.
